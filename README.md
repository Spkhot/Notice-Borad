# Public Notice Board

A simple public notice board where anyone can write, view, copy, and delete messages.

## Features

* Post text messages
* View all messages
* Copy messages
* Delete messages
* Data stored in MongoDB
* Single-page application

## Installation

```bash
npm install
```

## Setup

Create a `.env` file:

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```

## Run

```bash
npm run dev
```

or

```bash
npm start
```

Open:

```
http://localhost:5000
```

## Tech Stack

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MongoDB
